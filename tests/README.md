# 測試與驗收（行為驗證 / G4）

本 skill 是 prompt-based，驗證＝把 SKILL.md 規則套到測試輸入、檢查輸出行為。
驗收門檻（全綠才算過）：

| 項目 | 方法 | 通過標準 |
|---|---|---|
| **泛用性** | 對 `fixtures/written_inputs.md` 的書面/AI 稿（多領域、非滑雪）套 skill | 輸出口語自然、過自帶反 AI 清單；通過率 ≥90% |
| **誤傷（硬）** | 對 `fixtures/spoken_inputs.md` 的「本來就口語」稿套 skill | 改動率 ≤5%、0 語意改變 |
| **有效性** | 對書面稿套 skill | 改動率 ≥20% 且客觀更口語（平均句長下降、書面連接詞歸零、出現換氣斷行） |
| **仲裁準確率** | 對 `../references/arbitration_cases.md` 15 例，比對 skill 判斷與正解 | ≥90%（≥14/15） |
| **盲測** | 改後稿 vs 真人口語逐字稿並排，由獨立評審分辨 | 分辨率 ≤60%（接近隨機） |
| **紅隊** | skeptic 主動找破綻（過改好稿／改不動明顯書面／誤仲裁／過度灌語氣詞） | 無致命缺陷 |

## 量測工具
- 句長 / 連接詞 / 語氣詞 / 標點等客觀指標：用 `_tools/analyze.py`（對 before / after 各跑一次比較）。
- 改動率：以句為單位，改動句數 / 原句數（整句動算整句）。

## 輸出
驗證結果寫到 `acceptance_report.md`（逐項打勾＋數據）。未過項退回 Phase 3 修 SKILL.md，最多 5 輪。

## 注意
fixtures 為**合成**輸入（公開安全），不含語料庫原文。真實語料的「誤傷回歸」另以私有 `_corpus/` 抽樣補測（不入公開 repo）。
