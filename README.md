# humanizer-zh-speech

把書面腔／AI 腔的**繁體中文口播稿**，改寫成念出口像真人在講的自然口語——同時清掉中文 AI 寫作痕跡。

> 一句話：**把「寫出來給人讀」的中文，變成「念出來給人聽」的中文。**

這是 [`humanizer-zh`](https://github.com/blader/humanizer) 的姊妹 skill：
- `humanizer-zh` 處理「書面文字像不像 AI 寫的」（給人**讀**）。
- `humanizer-zh-speech` 處理「這段話念出來像不像真人在講」（給人**聽**）。

## 它解決什麼問題

你把一篇文章、或 AI 生出來的稿，直接拿去當**影片旁白／Podcast 講稿／YouTube 口白**念——
聽起來會「卡卡的、像在讀稿、很假」。

原因是：**書面中文和口語中文是兩套語體**。
寫給眼睛看的句子（長、主從嵌套、靠標點斷句、人稱稀疏），
和念給耳朵聽的句子（短、一口氣一個意念、靠換氣斷句、一直在對你講話），
結構根本不一樣。

市面上多數「口語化」只是把句子改短、加幾個「然後」。
這個 skill 不是憑感覺——它依**真實口播語料的量化研究**，逐一維度把書面改成口語，
而且**會克制**：對「本來就很口語」的稿，改動率應 ≤5%，不為改而改。

典型用途：
- 影片旁白稿、Podcast 講稿、Reels／短影音口白
- 把 AI 寫的稿「降書面腔」變成能直接開麥念的稿
- 給創作者校準「念起來像自己在講話」的個人口吻

## 研究基礎：不是憑感覺

規則的來源是一份自建語料研究：
**435 份台灣 YouTube 真人口播逐字稿**（6 大領域）對照 **25 篇正式書面文章**，
量化出兩套語體的真實差距：

| | 口語 | 書面 | 差距 |
|---|---|---|---|
| 平均句長 | **9.8 字** | 48.9 字 | 書面是口語的 **5 倍** |
| 句末標點覆蓋率 | 0.5% | 91.2% | 口語幾乎不打句號，靠氣口斷句 |
| 語氣詞密度 | 高 | — | 口語是書面的 **36 倍** |
| 口語連接詞（所以／然後／其實） | 高 | — | 口語是書面的 **9 倍** |
| 人稱代詞密度（我／你／大家） | 高 | — | 口語是書面的 **4.3 倍** |

完整 12 維分析、跨領域口語強度梯度、誠實邊界，見
[`references/speech_register_findings.md`](references/speech_register_findings.md)。

## 訓練語料：取樣自哪些頻道

口語語料**全部來自台灣創作者的 YouTube 人工字幕逐字稿**（人工字幕的斷行高度貼合說話者的自然換氣，
是韻律分析的黃金樣本）。涵蓋 6 大領域、25 個頻道，刻意橫跨「最正式（財經）到最隨意（生活）」的語體光譜，
讓 skill 的三檔口語強度有真實數字當依據。代表性來源：

| 領域 | 代表頻道 | 這個領域貢獻什麼 |
|---|---|---|
| 知識科普 | 泛科學 PanSci、蒼藍鴿的醫學天地、啟點文化 | 講解清楚但不浮誇的「中性」口吻基準 |
| 財經投資 | M 觀點、清流君、游庭皓的財經皓角、阿格力博識 | 句最長、術語密、語氣詞最少——**最正式**的「穩重檔」 |
| 教學語言 | 阿滴英文、VoiceTube、均一教育平台、數學老師張旭 | 互動引導、第二人稱對話感 |
| 時事評論 | 志祺七七 X 圖文不符、呱吉、范琪斐的美國時間、敏迪選讀 | 對談式爆炸短句、口語連接詞密度最高 |
| 影視說書 | 文森說書、NeKo 嗚喵、祖寧、部長 | **講稿型旁白**（先寫稿再念）——最貼「把書面稿改口播稿」的用途 |
| 生活 vlog | 黃氏兄弟、千千進食中、阿滴日常、林宣 Xuan Lin | 語氣詞最濃、最隨意的「閒聊檔」 |

> **版權與倫理**：本 repo **不重新散佈任何頻道的字幕或逐字稿原文**。
> 語料只用來計算**聚合統計**（句長、詞頻、密度等），公開版僅含這些統計數字，
> 以及為說明 pattern 而放的**≤15 字、去識別、不標頻道**的極短引用。
> 原始語料庫（`_corpus/`）以 `.gitignore` 排除，不進公開 repo。
> 此處點名頻道是為了交代「語體樣本取自哪種真實內容」，屬語料研究的來源揭露，
> 不代表這些創作者參與或背書本專案。

## 它會做的事

切短長句（一行一口氣 ≤10 字）→ 換口語連接詞（因此→所以、然而→但是）→
去名詞化（「進行討論」→「來聊」）→ 省多餘主語 → 拉第二人稱對話 →
按換氣斷行 → 補**功能性**語氣詞（克制，不堆口頭禪）。

**三檔口語強度**可調：
- **穩重**（知識／財經旁白）：句可略長、語氣詞稀疏
- **中性**（預設）：講解清楚、適度互動
- **閒聊**（vlog／談話）：短句、語氣詞濃、即興感

預設偏穩重——因為「先寫稿再念」的講稿型口播，句子短但語氣詞克制，
不該被灌成浮誇的即興口吻。

**不會做的事**：不改技術內容、數字、專有名詞、立場；不做事實查核；不是翻譯。

## 安裝

**一行安裝（推薦）**——透過 [skills CLI](https://skills.sh)，自動偵測你的 agent（Claude Code／OpenCode／Cursor…）：

```bash
npx skills add KyrieHuang/humanizer-zh-speech
```

裝到全域（所有專案共用）加 `-g`；指定 agent 加 `-a claude-code`。

或手動把資料夾放進 skills 目錄：

```bash
git clone https://github.com/KyrieHuang/humanizer-zh-speech.git
cp -r humanizer-zh-speech ~/.claude/skills/
```

## 用法

在 Claude Code／支援 skills 的環境裡，直接說：

- 「把這段改成口播稿」
- 「這個旁白唸起來太書面，幫我口語化」
- 「讓這篇像在跟觀眾講話，但不要太浮誇」（→ 穩重檔）
- 「改成很像在閒聊的 vlog 口吻」（→ 閒聊檔）

要貼近你個人口吻：給 3–5 段你自己的口播逐字稿，skill 會萃取你的「聲音指紋」當個人化覆蓋層
（見 [`references/example_voice_profile.md`](references/example_voice_profile.md)）。

## 範例

**書面輸入**
> 在當前高度不確定的總體經濟環境之下，投資人之所以普遍感到焦慮，主要是因為利率政策的走向仍不明朗。

**口播輸出（中性檔）**
> 現在這個大環境啊，很不確定。
> 大家為什麼這麼焦慮？
> 說穿了就是利率。
> 到底要往哪走，還看不清楚。

## 設計與限制

- 以**繁體中文／台灣口語**為主。
- 語料偏「講稿型口播」（單人／雙人對鏡頭講述），最貼「把書面稿改成口播稿」的用途；不代表多人自由閒聊或正式演說語體。
- 書面對照樣本量較小（25 篇），所有「X 倍」倍率為**方向性指標**，非精確母體估計。
- 完整方法論與誠實邊界見 [`references/speech_register_findings.md`](references/speech_register_findings.md) 末段。
